# ربط الموقع بحسابات Google

## 1. Search Console

1. افتح https://search.google.com/search-console بحساب الشركة.
2. أضف خاصية من نوع Domain باسم `limo-egypt.com` بدون https أو www.
3. انسخ قيمة TXT التي تظهر. أضفها في إعدادات DNS لدى مزود النطاق وفق تعليماته، مع الإبقاء على السجلات الحالية.
4. ارجع إلى Google واضغط التحقق بعد انتشار السجل.
5. بعد نشر التعديلات، اختبر أن sitemap.xml تعمل على النطاق الأساسي ثم أرسل رابطها من Sitemaps.
6. افحص رابط كل خدمة بالعربية والإنجليزية من URL Inspection وسجل النتائج قبل طلب الفهرسة.

ملكية Domain تشمل النطاق الفرعي www أيضًا. إذا تعذر الوصول إلى DNS، يمكن استخدام URL Prefix وإثبات HTML بواسطة `GOOGLE_SITE_VERIFICATION`، لكنه لا يغطي تلقائيًا كل نسخ النطاق.

## 2. Google Analytics 4

1. افتح https://analytics.google.com بحساب الشركة وأنشئ حسابًا وخاصية للموقع.
2. اختر المنطقة الزمنية للقاهرة وعملة التقارير المناسبة للعمل؛ هذه الإعدادات لا تغير أسعار الموقع.
3. أنشئ Web data stream برابط الموقع الأساسي.
4. انسخ Measurement ID الذي يبدأ بـ `G-`، وأضفه إلى متغير الاستضافة `NEXT_PUBLIC_GA4_ID` ثم أعد بناء ونشر الموقع.
5. بعد تفعيل القياس المناسب لسياسة الخصوصية والجمهور، تحقق من Realtime/DebugView أثناء تصفح الموقع والضغط على واتساب والاتصال.
6. راجع الأحداث `whatsapp_click` و`phone_click` الموجودة في الكود. راجع نجاح إرسال نموذج الحجز بصورة مستقلة قبل اعتباره key event؛ ضغط التواصل ليس حجزًا مؤكّدًا.

لا تضف سكربت GA4 آخر فوق الإعداد الحالي حتى لا تتكرر القياسات. لا ترسل أسماء العملاء أو أرقام هواتفهم أو محتوى رسائلهم إلى Analytics.

## البيانات المطلوبة لإكمال الربط

- تأكيد رابط الموقع النهائي: https://www.limo-egypt.com أو https://limo-egypt.com.
- Measurement ID من GA4.
- حالة التحقق في Search Console، أو اسم مزود DNS للمساعدة في تحديد مكان إضافة TXT.

لا نحتاج كلمة مرور حساب Google. هذه الخطوات لم تُنفذ في الحسابات بعد.
