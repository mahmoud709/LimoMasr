# تحسين صفحات الخدمات — 5 أكتوبر 2026

تمت إضافة دليل حجز خاص بكل خدمة، بالعربية والإنجليزية، داخل صفحات السيارات والفنادق والشقق الفندقية والفاست تراك والطيران. الدليل يشرح البيانات المطلوبة، ويعرض ثلاثة أسئلة حجز لكل خدمة وروابط لبقية الخدمات. المحتوى يُعرض من السيرفر؛ الأسئلة قابلة للفتح بعناصر details دون JavaScript إضافي.

تم توضيح H1 لكل خدمة، وربط أزرار واتساب المشتركة برقم الخدمة المناسب بدل توجيه جميع الصفحات إلى رقم السيارات.

لا توجد أسعار أو ضمانات أو سياسة إلغاء جديدة. الأسئلة تدعو العميل لمراجعة شروط العرض المحدد. لم تتم إضافة FAQ schema أو ادعاء استحقاق نتائج منسقة.

## مراجعة البيانات التشغيلية المطلوبة للمرحلة التالية

- السيارات: نطاق التغطية، السائق، سعة الأمتعة، الانتظار، رسوم الرحلات الإضافية والإلغاء.
- الفنادق: أسعار العروض وتواريخ صلاحيتها، نوع الغرف والوجبات والضرائب وشروط الدفع والإلغاء.
- الشقق: المرافق الفعلية والتنظيف والتأمين وشروط الدخول والخروج.
- المطارات: المطارات المخدومة وما تشمل كل باقة ومدة الحجز المسبق ونقطة اللقاء.
- الطيران: إجراءات الإصدار والدفع والتعديل؛ الشروط الخاصة بكل عرض تُراجع منفصلة.

## بعد النشر

1. افتح صفحة من كل خدمة بالعربية والإنجليزية وعلى الهاتف.
2. تأكد من ظهور دليل الحجز والأسئلة وعمل روابط اللغات والخدمات.
3. تأكد من توجيه واتساب إلى الرقم الصحيح لكل خدمة ومن وصول whatsapp_click.
4. راقب Search Console دون تكرار طلب الفهرسة لنفس الصفحة.

حالة القياس: تم إثبات Search Console، وقُبلت خريطة بها 58 رابطًا، وتم التحقق من وصول زيارات GA4 وwhatsapp_click وphone_click بالصور. تحديد الحدثين كأحداث رئيسية ينتظر ظهورهما في قائمة الأحداث الأخيرة. طلب فهرسة الصفحة الرئيسية العربية أُرسل؛ قبول الطلب لا يعني اكتمال الفهرسة.
