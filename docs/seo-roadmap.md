# خطة تنفيذ SEO — ليمو مصر

تاريخ البدء: 5 أكتوبر 2026. الأولوية متساوية لكل الخدمات.

## المرحلة 1: الفهرسة والقياس

- [x] عناوين ووصف مستقلان للرئيسية والسيارات والفنادق والشقق والفاست تراك والطيران ومن نحن والتواصل والمدونة.
- [x] canonical وhreflang لروابط /ar و/en، وعناوين تفاصيل السيارات والمقالات.
- [x] sitemap.xml ديناميكية للصفحات العامة والسيارات والمقالات المنشورة، دون تواريخ تعديل مصطنعة. تحتاج قاعدة البيانات للعمل.
- [x] robots.txt يسمح بالصفحات العامة وموارد العرض ويعلن خريطة الموقع.
- [x] noindex للإدارة وتسجيل الدخول والتسجيل وحجوزات العميل. هذا توجيه لمحركات البحث وليس وسيلة حماية بيانات.
- [x] H1 واضح للرئيسية وعنوان H1 في صفحات الخدمات التي تستخدم SectionHeader.
- [x] تجهيز متغير إثبات ملكية Search Console ومتغير GA4 اختياري. تتبع واتساب والاتصال موجود مسبقًا.
- [ ] نشر التعديلات على الاستضافة الحالية وفحص النتائج الفعلية.
- [ ] تأكيد النطاق الأساسي وتحويل HTTP والنسخة الأخرى من www إليه. النطاق المستخدم مؤقتًا وفق الخطة: https://www.limo-egypt.com.
- [ ] إنشاء/مراجعة Domain Property في Search Console وإثبات الملكية عبر DNS، ثم إرسال https://www.limo-egypt.com/sitemap.xml.
- [ ] فحص الرئيسية وكل صفحة خدمة بنسختي اللغة عبر URL Inspection وتسجيل حالة الفهرسة.
- [ ] تفعيل GA4 والتحقق من الأحداث والحجوزات في DebugView، وحفظ خط أساس لآخر 28 يومًا إن توفرت البيانات.

إعدادات الاستضافة المطلوبة (لا ترسل كلمات مرور):

```env
# Measurement ID من Google Analytics، اختياري حتى يتوفر الحساب
NEXT_PUBLIC_GA4_ID=G-XXXXXXXXXX
# فقط عند استخدام إثبات الملكية بوسم HTML؛ Domain Property يحتاج DNS
GOOGLE_SITE_VERIFICATION=verification-token
```

معيار القبول: صفحات الخدمات ترجع 200 ومحتوى صحيح وعنوانًا فريدًا وcanonical مطابقًا للغة؛ sitemap وrobots يعملان؛ الصفحات الخاصة تحمل noindex؛ أحداث التواصل تصل إلى GA4 دون بيانات شخصية. مراجعة الخصوصية والموافقة على القياس بحسب الجمهور المستهدف قبل تفعيل الحساب.

## المرحلة 2: تحسين المحتوى والحجز لكل الخدمات

| الخدمة | الصفحة الحالية | موضوع البحث الأولي | المطلوب |
|---|---|---|---|
| السيارات والليموزين | /cars | حجز سيارات وليموزين في مصر | توضيح وجود السائق، مسارات الرحلات، الأمتعة، التوافر، سياسة الانتظار والإلغاء |
| الفنادق | /hotels | حجز فنادق في مصر | شروط السعر والإقامة، الضرائب، الوجبات، تأكيد التوافر، أسئلة الحجز |
| الشقق الفندقية | /hotel-apartments | حجز شقق فندقية في مصر | مدة الإقامة، السعة، المرافق، شروط الدفع والتأمين |
| فاست تراك | /fast-track | فاست تراك مطارات مصر | المطارات الفعلية، ما تشمله الخدمة وما لا تشمله، الحجز المسبق |
| الطيران | /flights | طلب حجز طيران | إجراءات عرض السعر، الأمتعة، تعديل الحجز، شروط شركة الطيران |

هذه موضوعات أولية وليست كلمات ثبت حجم البحث عليها. نختار الصيغ والمدن النهائية بعد بيانات Search Console وبحث الطلب والمنافسين. لكل دورة تنفيذ نطور صفحة من كل خدمة ونقيس أثرها. لا ننشر وعودًا أو أسعارًا أو مواصفات غير مؤكدة.

معيار القبول: نص مفيد وفريد، عنوان رئيسي واحد، صور بوصف مطابق، أسئلة ظاهرة وإجابات صحيحة، وروابط حجز وتواصل تعمل على الهاتف.

## المرحلة 3: البيانات المنظمة والأداء

- بيانات Organization من اسم الشركة والهاتف والشعار والروابط الاجتماعية المؤكدة. LocalBusiness فقط عند توافر معلومات النشاط المطلوبة.
- Service وBreadcrumbList حيث يطابقان المحتوى الظاهر؛ لا نضيف تقييمات أو أسعارًا غير موثقة ولا نعد بظهور FAQ في النتائج.
- قياس PageSpeed للهاتف والكمبيوتر لكل خدمة، وحفظ النتائج قبل/بعد.
- تحسين أكبر صورة مرئية وحجم الصور وأبعادها وتأجيل الصور غير المرئية وتقليل JavaScript حسب نتائج القياس.
- فحص أي مقالات إنجليزية تعرض محتوى عربيًا بسبب نقص الترجمة؛ إكمال الترجمة أو تعديل سياسة نشر نسخ اللغة قبل توسيع الفهرسة.
- مراجعة /stays والفلاتر والسياسات والخصوصية وقرارات canonical بحسب اختلاف محتواها عن صفحات الفنادق والشقق.

## المرحلة 4: التوسع في الصفحات والظهور المحلي

- صفحات مستقلة للمطارات والمدن والخدمات المؤكدة فقط، بمحتوى يشرح تفاصيل كل خدمة ومكان.
- تفاصيل السيارات موجودة؛ نطورها بدل إنشاء نسخ مكررة لنفس السيارة.
- مراجعة Google Business Profile: الاسم والهاتف والعنوان أو مناطق الخدمة والصور وساعات العمل وفق النشاط الحقيقي.
- طلب تقييمات حقيقية من العملاء، دون حوافز مشروطة أو انتقاء العملاء الراضين فقط.

## المرحلة 5: المحتوى والسمعة والمتابعة

- أدلة أصلية تخدم أسئلة حجز الفنادق والسيارات والشقق والمطارات والطيران، وتربط بصفحات الخدمات ذات الصلة.
- روابط من شركاء وفنادق ومصادر سفر ذات صلة، دون شراء روابط هدفها التلاعب بالترتيب.
- متابعة أسبوعية للأخطاء وصفحات الفهرسة، ومراجعة كل 28 يومًا للنقرات والظهور والتحويلات حسب الخدمة واللغة.

## لوحة القياس

سجل البداية والنتيجة لكل خدمة: النقرات غير المرتبطة باسم الشركة، مرات الظهور، نسبة النقر، صفحات مفهرسة، ضغطات واتساب والاتصال، الطلبات الناجحة والحجوزات المؤكدة. الضغط على واتساب ليس حجزًا مؤكّدًا. قارن فترات متساوية مع مراعاة الموسم والبلد والجهاز واللغة؛ متوسط الترتيب مؤشر مساعد.

## حدود الفحص الحالي

الفحص الحالي للكود المحلي والخطة المرفقة. لم تسمح أداة الويب بقراءة الموقع المباشر، ولم نصل إلى Search Console أو GA4 أو DNS أو الاستضافة؛ لا توجد نتائج ترتيب أو سرعة أو فهرسة فعلية موثقة حتى الآن. التعديلات المحلية لا تؤثر على الموقع الحي قبل نشرها.
